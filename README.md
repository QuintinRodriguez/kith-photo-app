# Kith - Human Photo Journal

A privacy-focused, human-verified, chronological photo-sharing web application built with React, Vite, Tailwind CSS, TanStack Router, and Supabase.

## Features
- **Chronological Feed**: Pure timeline, no algorithmic feed manipulation or short-form video reels.
- **Privacy First**: Strips EXIF metadata before upload, granular audience controls (Public, Kith & Kin, Private).
- **Productivity & Wellbeing**: Session mindfulness warnings, daily time caps, toggleable follower/like counters.
- **Creator Economy**: Direct brand inquiry workflows and media kit profile pages without data surveillance.

## Architecture
- Frontend: React 18, Vite, TypeScript, Tailwind CSS, Lucide icons, shadcn/ui.
- Routing: TanStack Router.
- Backend/Database: PostgreSQL / Supabase, Row-Level Security (RLS).
